# OctoAcme Project Management Docs

This README centralizes OctoAcme's project management process documents and provides a brief summary of our approach. It links to each detailed process doc in the `docs/` folder.

## Brief summary of OctoAcme project management processes

OctoAcme runs cross-functional projects with a clear lifecycle: Initiation, Planning, Execution, Release, and Retrospective. We emphasize iterative delivery, clear ownership (PM + Product Lead), measurable outcomes, and continuous improvement. Teams follow a lightweight cadence of daily standups, weekly delivery syncs, sprint demos, and regular retrospectives. Key artifacts include a Project One-pager, prioritized backlog with acceptance criteria, a Risk Register, and release notes.

## How to use

Use this README as the entry point for understanding OctoAcme's project management approach. It helps new contributors quickly find the right process doc for initiation, planning, delivery, risk management, release, and retrospectives.

## Project lifecycle at a glance

1. Initiation: define the problem, stakeholders, and success metrics.
2. Planning: align scope, milestones, backlog, and responsibilities.
3. Execution: deliver iteratively with daily updates, reviews, and tracking.
4. Release: validate quality, deploy with controls, and communicate status.
5. Retrospective: capture lessons learned and drive continuous improvement.
